# Security

Report vulnerabilities privately through GitHub security advisories after publication.

Never include API keys, authorization headers, cookies, signatures, calldata, decoded data, or raw service responses in reports. Capture performs read-only HTTPS GET requests. It never signs or broadcasts transactions.

Snapshots contain public-chain and service metadata that can expose operational patterns. Store and share them accordingly. File mode `0600` is best effort on Windows and is not a confidentiality guarantee.
